# ОРДА HULI — Предвестники Долгой ночи

Одностраничный статический сайт альянса HooliGuns, 93-е королевство Last Asylum.

Опубликован через GitHub Pages: https://feniksleks.github.io/huli-manifest/

Сайт работает без сборки и сервера. Для локального просмотра откройте `index.html`.
Все изображения взяты из материалов, предоставленных для проекта, и преобразованы в WebP. Текст манифеста перенесён из `ОРДА HULI.docx` без сокращений; финальная строка изменена по просьбе автора на «Мы идем.....».

Шрифты Manrope и Prata размещены локально. Их лицензии находятся в `assets/fonts/`.

Финальная сцена `assets/final-march.webp` создана по предоставленным изображениям: вождь и воины со спины, поднятая рука как приказ к выступлению, армия у горизонта. Текст поверх сцены остаётся обычным HTML.
